TTL общий для всех правил CAPTCHA этого soft-block-сайта.

Что выполнить на сервере, чтобы CAPTCHA заработала:
  1. Найдите ID сайта в /etc/antiddos/config.json, в разделе soft_block.sites. В интерфейсе это блок Soft-block на странице правил. Например: 
    "soft_block": {
  "sites": {
    "site": { "hosts": ["example.com"], "log_sources": ["web"] }
  }
}
    Здесь ID сайта — site.
  2. sudo /usr/local/bin/antiddos nginx-snippet --config /etc/antiddos/config.json --site <site_id> --output /etc/nginx/snippets/antiddos-<site_id> --write
  3. Откройте /etc/nginx/snippets/antiddos-<site_id>/README.txt и подключите указанные там include в Nginx; затем добавьте worker Nginx в группу antiddos-check.
  4. sudo nginx -t && sudo systemctl restart nginx antiddos antiddos-challenge
Проверить подключение: sudo /usr/local/bin/antiddos soft-block doctor --config /etc/antiddos/config.json --site <site_id>. Документация.
